# Przewodnik Eteryu.space

Oficjalne repozytorium przewodnika po prywatności, bezpieczeństwie i cyfrowej wolności. Znajdziesz tutaj źródła całej strony: bazę wiedzy, rekomendacje narzędzi, artykuły oraz utwardzone konfiguracje oparte na architekturze Zero Trust.

Celem projektu jest dostarczenie konkretnych, sprawdzonych metod redukcji ryzyka i odzyskania kontroli nad własną cyfrową tożsamością. Wszystkie treści powstają niezależnie, bez reklam i bez sponsorowanych materiałów.

## Struktura projektu

- **Baza wiedzy** — fundamenty prywatności i bezpieczeństwa: modelowanie zagrożeń, menedżery haseł, bezpieczny DNS
- **Rekomendacje** — katalog narzędzi i konfiguracji przeglądarek
- **Artykuły** — dłuższe teksty o cyfrowej higienie, GrapheneOS i realnych przypadkach z życia
